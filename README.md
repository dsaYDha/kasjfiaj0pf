# 미궁 — 지하 3층

브라우저에서 바로 돌아가는 3D 1인칭 미로 공포게임입니다. Three.js(r128, CDN) 하나만 쓰고, 텍스처와 사운드는 모두 코드로 생성합니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. (Three.js와 폰트를 CDN에서 받으므로 인터넷 연결이 필요합니다.)

로컬 서버로 띄우려면:

```sh
npx http-server -c-1 .
```

## 목표

정전된 관리동 지하 3층. 미로 곳곳의 막다른 길에 흩어진 **열쇠 3개**를 모아 잠긴 **비상구**로 탈출합니다. 그동안 미로를 배회하는 "그것"에게 잡히면 끝입니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` / 방향키 | 이동 (←/→ 는 회전) |
| 마우스 | 둘러보기 (클릭하면 포인터 잠금, 안 되면 드래그) |
| `Shift` | 달리기. 숨이 차고 발소리가 커진다 |
| `F` | 손전등 켜기/끄기 |
| `M` (누르고 있기) | 지나온 길이 적힌 지도 |
| `Esc` / `P` | 일시정지 |

휴대폰에서는 왼쪽 조이스틱으로 이동, 화면 오른쪽을 끌어서 시점 이동, 버튼으로 손전등/달리기/지도를 씁니다.

## 게임 구조

- **미로**: 시드 기반 재귀 백트래킹(12×12 셀)에 고리 통로를 더해 도망칠 길을 만듭니다. 판마다 새 미로입니다.
- **그것**: 격자 BFS로 길을 찾습니다. 배회 → (보이거나 소리가 들리면) 추적 → 놓치면 마지막 위치 수색.
  - 손전등을 켜 두면 17m 밖에서도 들키고, 끄면 6.5m 안에 들어와야 들킵니다.
  - 달리면 13m 반경에 발소리가 들립니다. 열쇠를 주우면 그 자리로 몰려오고 점점 빨라집니다.
- **손전등 배터리**: 켜 두면 닳습니다. 막다른 길의 건전지로 충전합니다.
- **사운드**: Web Audio로 합성한 환기구 바람, 형광등 소음, 심장 박동(거리에 따라 빨라짐), 그것의 숨소리·발소리(HRTF 입체음향), 먼 곳의 노크·속삭임. 헤드폰을 쓰면 방향이 들립니다.
